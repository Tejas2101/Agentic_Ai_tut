## What is json 
- Also known as **JavaScript Object Notation**
- Used for Data Representation Format.
- Commonly used for APIs and Configs.
- Lightweight and easy to Read/Write for both humans and other programming languages.
- Integraes easily with most languages.

## Json types

- Strings - "Hello"
- Numbers - 10, 1.5, 18
- Booleans - true, false
- null - null
- Arrays - [1,2,3,4,5]
- Objects(The most important one which uses key value pair) - {"key" : "Value"} ("age" : 30).

- File name ends with **.json** extension.
